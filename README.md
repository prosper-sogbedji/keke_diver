## 🚀 Fonctionnalités Principales

- **Authentification Sécurisée** : Connexion via numéro de téléphone et vérification par OTP.
- **Gestion de Profil** : Configuration du profil chauffeur et détails du véhicule.
- **Navigation Intégrée** : Carte interactive pour la gestion des courses.
- **Support des Véhicules** : Gestion des différents types de transport (Moto, Tricycle, Voiture).

## 🛠️ Technologies Utilisées

- **Framework** : Flutter (Dart)
- **Gestion d'état** : Riverpod
- **Réseau** : Dio
- **Stockage Local** : Flutter Secure Storage, Get Storage
- **Design** : Flutter ScreenUtil, Animations (Flutter Animate)

## 📦 Installation et Lancement

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/prosper-sogbedji/keke_diver.git
   ```
2. Installez les dépendances :
   ```bash
   flutter pub get
   ```
3. Lancez l'application :
   ```bash
   flutter run
   ```
